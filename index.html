What’s in this folder

engine/
The runtime: plays any game in games/. engine/index.html?game=<id> plays one. engine/SPEC.md is the technical reference.
games/
One folder per game: its game.js (title screen, packs, words), its asset packs (levels, monsters, items, tile sets, furniture, people) and its editor changes. Any game can load another game’s packs.
editor/
The Linear Maze Editor. It stands on its own: give someone this folder and they can open any workspace with it.
tools/
node tools/package.mjs <id> writes a game for players into dist/: the engine plus that game’s files, as a folder and as one HTML file.
