# The Bunker

Age of War command bunker, Threat Level 1, 2 floors, seed `11`, library `1ebxgef`, generator 0.1.0.

**Back-story.** A warlord’s army cut it into the hill as a forward command post. It was meant to run the war for the near-area. The war moved on and forgot to tell it. The garrison sealed the doors against the Burners and waited for relief, counting the days on the inner door. The guard robots never got the order to stand down. The roaches got in anyway.

**Goal.** Recover the duty log.
