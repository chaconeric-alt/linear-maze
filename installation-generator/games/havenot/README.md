# HaveNot: The Near-Area

A vertical slice of HaveNot (the JAGS setting) on the next-gen engine. Play it at `engine/index.html?game=havenot`, or pick it in the launcher.

You make a scavenger, leave a home bunker, and loot the near-area. A **mission** starts when you step outside and ends when you come back home: that's when kits and charges refill. Death ends the run.

## Packs

| Pack | What's in it |
|---|---|
| `hn-rules` | Run state (`LM.HN`), character creation (3 origins, 3 gear packages, 3 kits, random mutations), the item catalog, weapons and armour, melee and bites, grenades, cookies as bait, hacking, the bestiary, world fixtures (caches, crates, terminals, security panels, kiosk, mists, health stations, the Personal Shopper), and the epilogues |
| `hn-world` | The area map: 11 pins, location panels, travel, discovery |
| `hn-sites` | Home, the Out-rider Outpost, Boom-Town and Mother Long-Legs' den; vendors (buy, and sell at a tenth), medics, rumors, the Expedition Ledger, NPCs and their small quests |
| `hn-anomalous` | The Anomalous Structure, three floors: the Sphinx Gun, kiosk, Blue/Yellow/Red cards, the Monoid, the round Testing Chamber (three modes), the bio lab, the prototype vault, the Security Station, the Repair Bay, the armory and the inner core |
| `hn-stubs` | The Warren and the Bolt Hole: one sealed entry room each, so the pins work (the Bunker's stub is excluded now) |
| `hn-gen-kit` | What generated installations need at run time: pins for new sites, taking over a stub's pin, trap switch-offs, roaches between missions, the done toast |
| `hn-g-bunker` | The Bunker (Installation B), generated: two floors at Threat Level 1. `gen/briefs/bunker.json` is its brief; `REPORT.md` in the pack has its locks and keys |

It also loads `linear-maze/core`, the office pack's items, and `havenot-test/hn-complex` for shared set dressing.

## Things to know when editing

- `hn-g-…` packs are made by the installation generator (`editor/gen/README.md`): `node tools/generate.mjs havenot --brief bunker --add` remakes the Bunker. Its lists are in `gen/library/`, what's in the game in `gen/corpus.json`. Edit a generated pack like any other; the generator README says how to keep hand edits.

- Floor maps are generated by small Python scripts outside the repo, then hand-checked. Edit the level files directly from now on; the editor's map tools work on them.
- Story state lives in flags on the player (`hn…`) plus `LM.HN.st(game)` (saved with the run).
- Monsters never drop healing or ammo. Robots drop fuel cells and salvage; bio-weapons drop nothing.
- Between missions, Gladiator Roaches come back (up to 5 per floor), and while the Repair Bay runs it rebuilds up to 2 robots per floor. Nothing else respawns.
- `ART-PROMPTS.md` has the prompts for every picture and sprite that's still procedural.
